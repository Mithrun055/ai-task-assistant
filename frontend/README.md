# AI Task Assistant

A full-stack AI application that accepts user requests and returns structured, 
AI-generated responses using React, FastAPI, and CrewAI.

## Tech Stack
- **Frontend**: React 19 + Vite + Tailwind CSS
- **Backend**: Python + FastAPI
- **AI Agents**: CrewAI (Planner Agent + Reviewer Agent)
- **LLM**: Groq (LLaMA 3.3 70B)
